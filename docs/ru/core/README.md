# Модуль `core`

[English](../../en/core/README.md)

Модуль `core` содержит внутреннюю семантическую модель API-документа, средства навигации, разрешения локальных ссылок и атомарного редактирования через команды.

Модуль написан на чистой Java без внешних runtime-зависимостей и не привязан к формату сериализации (YAML/JSON) или конкретной минорной версии спецификации OpenAPI 3.x.

## Принципы устройства

- **Стабильная идентичность.** Основные элементы документа имеют собственный внутренний идентификатор (`ElementId` на базе UUID), который не зависит от их имени или пути в документе и сохраняется при переименовании.
- **Защита от прямой мутации.** Модели безопасны для чтения снаружи: все коллекции доступны только для чтения, а при создании и копировании объектов выполняются глубокие копии. Изменение существующего документа возможно только внутри сессии редактора.
- **Поддержка черновиков.** Структурная валидация проверяет только целостность дерева объектов, уникальность идентификаторов и отсутствие конфликтов имён в одном пространстве. Неполные или семантически незавершённые описания разрешены, чтобы документ можно было собирать и редактировать пошагово.
