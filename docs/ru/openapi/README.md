# Импорт и редактирование исходника OpenAPI

[English](../../en/openapi/README.md)

Модуль `openapi` принимает байты документа и интерпретирует YAML или JSON как OpenAPI. Он зависит от `core`; загрузка файлов, получение URL и сохранение документов относятся к вызывающей стороне. Исходник хранится отдельно от частичной семантической модели, поэтому неподдерживаемые разделы документа не отбрасываются при импорте.
